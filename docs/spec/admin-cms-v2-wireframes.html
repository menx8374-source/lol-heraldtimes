運営CMS v2 画面ワイヤーフレーム（グレースケール／構造のみ）

「どの画面に、どの情報と操作が並ぶか」だけを示す簡易ワイヤーフレームです。配色・フォント・コンポーネント構成などの 実装判断は含みません。角括弧付きの矩形は UI 要素のプレースホルダーです。既存画面（/admin ダッシュボード）に対しては 追加するパネルを明示しています。
