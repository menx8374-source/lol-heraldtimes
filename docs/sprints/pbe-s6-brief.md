# PBE-S6 — PBEアイテムdiffの品質改善（日本語・ノイズ無し・実在アイテムのみ）＋件数文言削除＋サムネ付与

実データ（PBE 16.16）で見つかったPBE記事の品質問題を修正する。**AI不使用・opt-in（既存挙動不変）**。対象: Web。

## 背景（実データで判明した問題）
PBE記事 `/articles/pbe-16.16` を実データで確認した結果:
1. **アイテムの変更「説明」が英語のまま**（例「Noxian Gait Attacks against Champions grant Move Speed…」）。CDragonのja_jpロケールでも `description` が英語のため。
2. **ノイズな差分**：例 ラストウィスパーの変更が `armor.` ⇒ `Armor.`（**大文字小文字の違いだけ**）、説明文が丸ごと重複表示。実質変更でないものが「変更」として出る。
3. **アイテム名が誤り＝削除済み/非SRアイテムの混入**（例「エリーサの奇跡」＝Eleisa's Miracle、「デスファイア グラスプ」＝Deathfire Grasp は削除済みアイテム）。CDragon items.json に残る非店売り/内部アイテムを拾ってしまっている。
4. **冒頭の件数文言が不要**：「PBE {ver} 時点で、チャンピオン{N}体・アイテム{M}件の変更が確認されています…」（特に「チャンピオン0体」が不体裁）。
5. **サムネ画像が無い**（通常のパッチ記事は公式バナー等があるが、PBE記事はサムネ未設定）。

## 含まれる機能

### F-PBE6-1: アイテムdiffを「実在アイテムのみ・日本語・意味のある変更だけ」に（pbe-item-diff.ts）
generatorは**実際のCDragon PBE items.json（`raw.communitydragon.org/pbe|latest/.../ja_jp/v1/items.json`）をcurlで確認**し、以下を実装する:
- **実在の店売りアイテムのみに絞る**: `inStore: true`（かつ必要なら `iconPath` があり `requiredChampion` 無し等）の通常アイテムだけを対象にし、**削除済み/非店売り/内部アイテム（Eleisa's Miracle・Deathfire Grasp 等）を除外**する（＝報告③のアイテム名誤りを解消）。実データで除外条件が妥当か確認すること。
- **英語の自由記述（description prose）の差分は出さない**（大文字小文字・言い回しのノイズ源＝報告①②を解消）。
- **意味のある「ラベル明瞭・言語非依存 or 日本語化できる」変更だけ**を出す:
  - **価格**（`priceTotal`）: 数値なので言語非依存。「価格 2500 ⇒ 2600（ゴールド）」。
  - **ステータス数値**: descriptionの `<stats>` 等から抽出できる「数値＋ステータス種別」を、**英語→日本語のステータス名対訳（小さなglossary）**で日本語化して出す（例 "65 Ability Power" → 「魔力 65」、"Attack Speed" → 「攻撃速度」、"Cooldown Reduction" → 「クールダウン短縮」、"Health" → 「体力」、"Move Speed" → 「移動速度」等。対訳が無い項目は無理に出さず除外＝誤情報回避）。
  - 価格・ステータス数値のいずれにも**意味のある差分が無いアイテムは除外**（変更0件は出さない）。
- **逐語維持・捏造禁止**（数値はCDragonの値そのまま。英語プロースを機械翻訳して載せない＝誤訳回避。ラベルのみ既知の対訳で日本語化）。

### F-PBE6-2: 冒頭の件数文言を削除（pbe-compose.ts）
- 冒頭サマリの「PBE {ver} 時点で、チャンピオン{N}体・アイテム{M}件の変更が確認されています（スキル効果量の詳細は公式パッチノートで確定）。」の**件数を数える文を削除**する。
- 代わりに（必要なら）簡潔な導入のみ（例「PBE {ver}（テストサーバー）で確認された変更のまとめです。正式な数値は公式パッチノートで確定します。」＝件数を数えない・「0体」を出さない）。未確定バッジ・目次・出典・「スキル詳細は公式で」は維持。

### F-PBE6-3: PBE記事にサムネイル画像を付与
- PBE記事に `thumbnailUrl` を設定する（通常記事と同様に一覧・OGPでサムネが出るように）:
  - チャンピオン変更があればそのチャンピオンのスプラッシュ/アイコン（既存 `buildChampionSplashUrl`/champion-splash）を優先。
  - 無ければ**変更のあった先頭アイテムのアイコン**（CDragonアイテムアイコンURL、既存 `buildCDragonItemIconUrl`）。
  - それも無ければ**既定のパッチ/PBEサムネ画像**（既存の default サムネ資産、無ければ `public/` に軽量な既定画像を用意 or 既存パッチ既定にフォールバック）。
- `isSafeImageUrl` で検証し、壊れURLは既定にフォールバック（記事は壊れない）。alt/credit付き。

## 制約・非目標
- **AIは使わない**（絞り込み・対訳・組み立ては純ルール/glossary）。**逐語維持・捏造禁止**（数値そのまま・英語プロースを翻訳しない・ラベルのみ既知対訳）。
- **opt-in厳守**（`PBE_ARTICLE_MODE` off/未設定で既存挙動不変・回帰ゼロ）。Xツイート統合（PBE-S5）・CDragonチャンピオンdiff（PBE-S2）・未確定バッジ・出典・LoLデザインは維持（今回はアイテムdiffの品質・件数文言・サムネのみ）。
- **DBスキーマ変更なし・新規npm依存なし**。CDragon/公式ノート/G7 X 反応記事は不変。

## テスト（必須・実HTTPを叩かない・固定フィクスチャ）
1. `diffItems`: 実データ相当のフィクスチャで、**inStore=true の実在アイテムだけ**が対象になり、削除済み/非店売りアイテムが除外される。
2. **英語プロースの差分（casing含む）が出ない**。価格差分は「価格 X ⇒ Y（ゴールド）」、ステータス差分は日本語ラベル（魔力/攻撃速度等）で出る。対訳の無いステータスは出さない。
3. 意味のある差分が無いアイテムは0件で出ない。逐語維持（数値そのまま）。
4. pbe-compose: 冒頭に件数文（「チャンピオンN体・アイテムM件…」）が**出ない**。未確定バッジ・目次・出典・Xセクションは維持。
5. サムネ: PBE記事に thumbnailUrl が付く（チャンピオン→アイテム→既定の優先順）。壊れURLは既定フォールバック。
6. 既存の pbe-item-diff/pbe-compose/pbe-article/G7 テストが回帰しない。

## 受け入れ基準
1. `npx vitest run` 全Green・`tsc`・`build`・`lint` 通過。
2. PBEアイテム欄が**実在アイテムのみ・日本語（ラベル対訳＋数値）・ノイズ無し**になる。冒頭の件数文が消える。PBE記事にサムネが付く。Xツイート統合・未確定・出典・LoLデザインは維持。
3. AI不使用・逐語維持・捏造なし・opt-in（既定off回帰ゼロ）・DBスキーマ変更なし・新規依存なし。

## 評価基準（evaluator向け）
- テスト全Green・build/tsc/lint通過・コンソールエラー0。
- 実CDragonデータで、削除済みアイテムが除外され、価格・ステータス（日本語ラベル）の意味ある変更だけが出る。件数文が無い。サムネが付く。
- 受け入れ基準1〜3を満たす。
