# 拡張E51 — 海外の反応(Reddit)翻訳を「コメント全体を文脈ごと自然な日本語」に改善

運用フィードバック起点。対象: Web（生成・翻訳）。

## 背景（なぜ）
現在のReddit翻訳（拡張E47/E49）は「**各レスを1行ずつ・行数厳密一致・意味を変えない**」方式で、文脈が行単位に分断され
**直訳的で硬く分かりづらい**。日本のLoLまとめ読者に**自然で伝わりやすい日本語**にしたい。

## 含まれる機能

### F-E51-1: 翻訳単位を「行」から「コメント全体」に変更（文脈を保つ）
- `src/lib/generation/compose.ts` の翻訳処理（`translateReactionLines` / `translateReactionBatch` / `normalizeTranslations` /
  `REACTION_TRANSLATE_SYSTEM_PROMPT` / タスク形状）を、**レス（コメント）単位の全文翻訳**に変える。
  - LLMへの入力: 各レスの**全文**（行を改行で結合したテキスト）を渡す。タスク例
    `{ kind:"reaction-translate", reses:[{ index, text }] }`。
  - LLMの出力(JSON): `{ translations:[{ index, text:"自然な日本語訳（1コメント分・複数文可）" }] }`。**行数一致の制約は撤廃**。
  - `normalizeTranslations`: `{index, text}` を検証（index実在・text非空文字列）し `Map<number, string>` を返す。

### F-E51-2: 自然な日本語にするプロンプトへ改善（直訳をやめる）
- `REACTION_TRANSLATE_SYSTEM_PROMPT` を書き換え、要旨:
  - 「あなたは日本の『海外の反応』まとめサイトの翻訳担当。Redditのコメントを、**まるで日本人プレイヤーが自分の言葉で
    書いたような、スッと頭に入る自然な口語の日本語**に翻訳する。**逐語訳・翻訳調を避け**、意味・ニュアンス・温度感が
    伝わる**こなれた日本語**にする（人気の海外の反応まとめサイトのように読みやすく）。」
  - 「英語のネットスラング・略語・LoL用語（チャンピオン名/レーン/BAN・ピック/ナーフ・バフ等）は、**日本のプレイヤーが
    普段使う自然な言い回し**に置き換える。皮肉・ジョーク・愚痴・煽り合いなどの**口調やテンションも日本語の口語で再現**する。」
  - 「一文が長い・回りくどいコメントは、**日本語として自然な短さ・語順に整えて**読みやすくしてよい（意味は保つ）。」
  - **捏造・改変の禁止は維持**: 「ただし**事実・数値・固有名詞（チャンピオン名/選手名/チーム名/スコア）は変えない・作らない・
    重要な情報を落とさない**。意訳・自然化はしてよいが、情報の追加/削除や事実の改変はしない。」
  - 「読みやすさ重視で自然な文に。ただし元コメントに無い過度な脚色・煽り増しはしない。」
  - 出力はJSONのみ（`{translations:[{index,text}]}`）。

### F-E51-3: 表示組み立ての追随（buildReactionDisplayLines）
- reddit で翻訳(text)がある場合: そのレスの表示を**自然な日本語テキスト**で組む。text に改行が含まれれば行に分割
  （空行は除去）、無ければ1行。各行は `{ text }`（**original は付けない＝拡張E50維持**）。
  - NG文削除（`removeNgSentences`）・行強調（`computeLineEmphasis`）は表示テキスト（日本語）に適用（従来どおり）。
  - 翻訳が全く無い（reddit失敗・5ch）: 従来どおり抽出行そのまま（`text` のみ・英語フォールバック）。
- バッチ分割（拡張E49）は維持（コメント全文の合計文字数でバッチを区切る）。あるバッチ失敗はそのレスだけ英語FB・他は活かす。

## 制約・非目標
- redditのみ。5ch/riot・hotness・SEO・moderation・強調色・サムネには触れない。新規依存なし。翻訳はlive時のみ（mockはseo同様に翻訳せず英語＝回帰なし）。
- 逐語（原文）保持は**しない**（E50で原文併記は廃止済み）。ただし**事実・数値・固有名詞は不変**をプロンプトで担保（意訳の範囲で自然化）。
- 翻訳のLLM呼び出し回数は増やさない（バッチ方式維持）。

## テスト（必須・実API/実ネット非依存＝スタブLLM）
1. `normalizeTranslations`: `{index, text}` 形式を検証（index実在・非空text採用、無効/空は除外）。`Map<index, string>` を返す。
2. `translateReactionLines`（スタブ）: コメント全文が渡り、`{translations:[{index,text}]}` を解釈して index→text を返す。バッチ分割・
   1バッチ失敗の部分フォールバック（該当レスのみ英語）を維持。
3. `buildReactionBlocks`（reddit・スタブ翻訳）: 各レスが自然な日本語 text で組まれる（original 無し）。改行含む訳は行分割される。
   NG文削除・強調が日本語に適用される。翻訳null→英語フォールバック。5ch は不変（翻訳未経由）。
4. プロンプトに「自然な日本語・直訳しない・事実/数値/固有名詞は不変・JSONのみ」の指示が含まれる（文字列確認）。
5. 既存の compose/reaction テストが新方式（全文翻訳・行数一致撤廃）に沿って回帰しない。

## 受け入れ基準
1. `npx vitest run` 全Green（新規/更新含む）。
2. `npx tsc --noEmit`・`npm run build`・`npm run lint` 通過。
3. Reddit記事のコメントが、文脈を保った**自然で読みやすい日本語**になる（直訳の硬さが減る）。事実/数値/固有名詞は不変・原文併記なし。
   翻訳失敗時は英語フォールバックで壊れない。5chは不変・新規依存なし・LLM呼び出し増なし。

## 評価基準（evaluator向け）
- テスト全Green・build/tsc/lint通過。mock/生成/表示が回帰しない（コンソールエラー0・5ch不変・reddit mockは英語）。
- コメント全文翻訳・自然文プロンプト・行数一致撤廃・原文なし維持がテストで確認できる。
- 受け入れ基準1〜3を満たす。
