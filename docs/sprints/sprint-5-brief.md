# Sprint 5 brief — 煽り速報タイトル生成と品質チェッカーを実装する（中核差別化）

> 仕様書 `docs/spec/lol-matome-sokuhou-spec.md` から Sprint 5 該当部分を原文のまま抜粋。generator/evaluator の主参照先。

## 対象プラットフォーム
`web`（自動運営のバックエンド／バッチ処理を含む）。

## ⚠ このスプリントの実装方針（LLM もモック）
**タイトル生成の LLM は当面モック／スタブ実装で進める**（ユーザー決定 2026-07-25: LLM 本接続もスキップし、まず全スプリントを通す）。architecture.md の `LLMClient` 抽象越しに呼び出し、既定は API キー不要の決定論的モック実装（ラベル語彙・具体要素抽出・感情フック語尾・文字数を満たす煽りタイトルをルールベースで生成する）にする。後日 Anthropic Claude へ差し替えられるよう抽象は維持。**品質チェッカー（ラベル／具体要素／感情フック／文字数の自動採点）は LLM 非依存の決定論ロジック**として実装し、自動テストで Green にする（合格例・不合格例の両方を含む）。**API キーは要求しない**。これは中核差別化要素なので、参考「Overwatch攻略まとめ速報@おばにゅー」の煽り・好奇心ギャップ型タイトルの再現を、モックであっても品質基準（10件で合格率90%以上）を満たす形で重視する。

## 含まれる機能: F8

### F8. 煽り速報タイトル生成（中核差別化機能）
- 説明: 「Overwatch攻略まとめ速報@おばにゅー」等に見られる、好奇心ギャップ・感情喚起型のまとめ速報タイトルを再現生成する。冒頭に【】ラベル（【速報】【悲報】【朗報】【朗報か？】【議論】【海外の反応】等）、具体要素（チャンピオン名・数字・パッチ番号・大会名等）、感情フックの語尾（「〜だった件」「〜がヤバい」「〜、判明」「〜で大荒れ」等）を含む、クリックを誘うタイトルにする。
- 優先度: Must
- 受け入れ基準:
  - [ ] 記事本文（または記事化候補）を入力すると、まとめ速報型のタイトル文字列が1本生成される。
  - [ ] 生成タイトルは冒頭に【】で囲んだラベル（あらかじめ定義したラベル語彙のいずれか）を1つ含む。
  - [ ] 生成タイトルは、記事内容に実在する具体要素（チャンピオン名・数値・パッチ番号・大会名・固有名詞のいずれか）を最低1つ含む（本文に存在しない固有名詞を捏造しない）。
  - [ ] 生成タイトルは、定義済みの感情フック（好奇心ギャップ／驚き／煽りの語尾・言い回し）パターンのいずれかに合致する。
  - [ ] 生成タイトルの文字数が定めた範囲（例: 全角20〜48文字相当）に収まる。
  - [ ] タイトル品質を自動採点するチェッカーがあり、上記4点（ラベル／具体要素／感情フック／文字数）を判定して合格・不合格を出せる。10件のサンプル記事に対して合格率が90%以上になる。
  - [ ] 同一記事に対して生成しても、ラベルや語尾のバリエーションが偏りすぎない（複数記事で全部同じラベル・同じ語尾に固定化されないことを確認できる）。
  - [ ] 差別的・過度に攻撃的な表現、実在個人を中傷する表現を含むタイトルは生成されない（安全フィルタ済み語彙で構成される）。

## このスプリントの受け入れ基準
- [ ] 記事本文または記事化候補を入力すると、まとめ速報型タイトルが1本生成される。
- [ ] 生成タイトルは冒頭に、定義済みラベル語彙（例: 【速報】【悲報】【朗報】【朗報か？】【議論】【海外の反応】等）のいずれか1つを【】付きで含む。
- [ ] 生成タイトルは、記事内容に実在する具体要素（チャンピオン名・数値・パッチ番号・大会名・固有名詞のいずれか）を最低1つ含み、本文に存在しない固有名詞を捏造しない。
- [ ] 生成タイトルは定義済み感情フック（好奇心ギャップ／驚き／煽りの語尾・言い回し）パターンのいずれかに合致する。
- [ ] 生成タイトルの文字数が定めた範囲（全角20〜48文字相当）に収まる。
- [ ] タイトル品質を自動採点するチェッカーが存在し、「ラベル有無・具体要素有無・感情フック合致・文字数範囲」の4点を判定して合格／不合格を返す。
- [ ] 用意した10件のサンプル記事に対し、チェッカーによる合格率が90%以上になる。
- [ ] 複数記事に対して生成したとき、ラベル・語尾が全て同一に固定化されず、バリエーションが出る。
- [ ] 差別的・過度に攻撃的・実在個人中傷の表現を含むタイトルが生成されない（安全語彙で構成される）。
- [ ] 生成タイトルが Sprint 1・2 の記事カードおよび個別記事ページのタイトルとして表示され、レイアウトが崩れない。

- 致命的バグ: 0件
- コンソールエラー: 0件
- 上記受け入れ基準の充足率: 100%
- タイトル品質チェッカーの判定ロジックの自動テストが Green（合格例・不合格例の両方を含む）
