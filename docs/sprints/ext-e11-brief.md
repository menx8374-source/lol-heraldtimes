# 拡張スプリント E11: 記事内の固定シェアバー（本物SNSアイコン）＋広告未設定枠の非表示

対象プラットフォーム: web（既存アーキテクチャに従う）

## 背景
参考サイト（おばにゅー）は、記事本文の左上あたりにSNSシェアボタンをスクロール追従で常時表示している。
Xでのシェアが最も多く使われる想定のため、これを目立つ位置に常時出す。あわせて、広告コード未設定時の
「広告枠（未設定）」プレースホルダーが実運用で不格好なため、未設定時は枠ごと非表示（空欄）にする。

## 含まれる機能

### F-E11-1: スクロール追従の固定シェアバー（本物アイコン・X最優先）
- 記事ページ（`/articles/[slug]`）に、スクロールしても常に同じ位置に留まる（sticky/fixed）シェアバーを追加する。
- 位置は記事の左上寄り（PC: 本文左側に縦並びで追従。おばにゅー準拠）。**Xを最優先・最上部**に配置する。
- SNSアイコンは各サービスの**本物のロゴアイコン**を使う（X, LINE, はてなブックマーク, Facebook 等）。
  外部CDNは使わず**インラインSVG**で実装する（各社ブランドロゴのパスをSVGで埋め込む。色・形はブランド準拠）。
  アイコンには適切な `aria-label`/`title`（例: 「Xでシェア」）を付ける。
- モバイル（狭幅）では縦の追従バーが本文に被らないよう、下部固定バーや折返し配置などの
  フォールバックにする（本文の可読性を損なわないこと）。
- シェアURL生成は既存の `lib/share.ts`（`buildShareUrl`）を流用・拡張する。新規タブ・`rel="noopener noreferrer"` を維持。
- 既存の記事下シェアボタン（`ShareButtons`）は残してよい（重複可）。本物アイコン化を共通化できるならする。

### F-E11-2: 広告未設定枠は空欄（何も描画しない）
- `AdSlot`（`components/ad-slot.tsx`）で、広告コードが未設定（`getAdSlotCode` が空/undefined）の場合は
  枠・「広告 / PR」ラベル・「広告枠（未設定）」プレースホルダーを**一切描画しない**（`null` を返し、余白も残さない）。
- 広告コードが設定されている場合は従来どおり「広告」ラベル付きの枠＋広告タグを表示する（誤認防止ラベルは維持）。
- これにより、本接続前（未設定）の画面には広告枠が見えず、設定後にのみ枠が現れる。

## 実装方針
- 追従バーはクライアントコンポーネント。CLS/被りを避けるためレイアウトを検証する。
- SVGアイコンは信頼済みの静的マークアップのみ（閲覧者入力を混ぜない）。`dangerouslySetInnerHTML` は使わずJSX/SVG要素で記述する。
- `AdSlot` の変更は表示分岐のみ。広告が設定されている場合の既存挙動・セキュリティ注意（信頼済みenv値のみ `dangerouslySetInnerHTML`）は変えない。

## 受け入れ基準（検証可能・原文）
- [ ] 記事ページでシェアバーが表示され、ページを下までスクロールしても位置が固定（追従）される。
- [ ] シェアバーの先頭（最優先）にXがあり、各SNSが本物のロゴアイコン（インラインSVG）で表示される。
- [ ] 各アイコンをクリックすると該当SNSの共有URLが新規タブで開く（X/LINE/はてブ等）。
- [ ] モバイル幅でシェアバーが本文に重ならず、可読性を損なわない。
- [ ] 広告コード未設定時、記事・一覧・サイドバー等の広告枠が一切表示されない（空欄・余白も残らない）。
- [ ] 広告コードを設定した場合は「広告 / PR」ラベル付きの枠が表示される（設定時の挙動は従来どおり）。
- [ ] ダークモードでシェアバー・アイコンの視認性が保たれる。
- [ ] `npm test` が全てGreen（AdSlotの未設定時非表示・シェアURL生成のロジックにテストを追加）。

## 評価基準（evaluator向け）
- 致命的バグ0件／コンソール・実行エラー0件／上記受け入れ基準の充足率100%／テストGreen。1つでも下回れば全体FAIL。
- Playwright MCP でスクロール追従・アイコン表示・シェアURL・モバイル幅・広告未設定時の非表示（env未設定）／設定時の表示を確認。プレビュー画像を保存すること。
- 広告設定時の表示は env に広告コードを一時設定して確認し、検証後に元へ戻す（コミットに含めない）。
