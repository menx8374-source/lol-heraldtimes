# 拡張スプリント E10: タグ一覧ページ＋カレンダー式アーカイブ（日付絞り込み）

対象プラットフォーム: web（既存アーキテクチャに従う）

## 背景
現状は `/tags/[tag]`（個別タグの記事一覧）と `/archive`・`/archive/[month]`（月別アーカイブ）はあるが、
タグの一覧画面が無く、アーカイブも月単位のみ。参考サイト（おばにゅー）同様、タグ一覧とカレンダー式の
日付アーカイブを追加する。

## 含まれる機能

### F-E10-1: タグ一覧ページ（`/tags`）＋タグでの検索
- `/tags` に全タグの一覧を表示する。各タグに紐づく公開記事数を併記し、タグをクリックすると
  既存の `/tags/[tag]`（該当記事一覧）へ遷移する。
- タグは記事数の多い順、または五十音/アルファベット順など、閲覧しやすい順序で並べる（タグクラウド的表示でも可）。
- グローバルナビ等からタグ一覧へ辿れる導線を追加する。
- 「タグでも検索できる」導線: 検索フォームまたはタグ一覧から、タグ名で該当記事に到達できること
  （既存の全文検索とタグ絞り込みのどちらでタグに到達させるかは自然な実装でよいが、タグ名での記事到達が成立すること）。
- 公開記事のみをカウント・対象にする（`PUBLISHED_ONLY` を維持。held/scheduled/rejected を数に含めない）。

### F-E10-2: カレンダー式アーカイブ＋日付絞り込み
- アーカイブ画面を、月カレンダー（日付グリッド）形式にする。記事が存在する日を視覚的に強調（バッジ/色）し、
  その日をクリックするとその日の記事一覧に遷移する。
- 日別アーカイブのルート（例: `/archive/[date]`、`date` は `YYYY-MM-DD`）を追加し、指定日の公開記事一覧を表示する。
- 前月/翌月への移動、記事のある月/日への導線を用意する。既存の月別アーカイブ（`/archive/[month]`）は残してもよいが、
  カレンダーUIから月・日を辿れるようにする。
- タイムゾーンは日本時間（JST, Asia/Tokyo）基準で日付を判定する（`publishedAt` の日付境界がJSTでずれないこと）。
- 公開記事のみ対象（`PUBLISHED_ONLY` 維持）。存在しない日付・未来日は空一覧（エラーにしない）。

## 実装方針
- タグ集計・日別集計は純関数＋DBクエリで有界に行う。カレンダーの「記事のある日」判定は、対象月の
  公開記事を集計して日ごとの件数マップを作る（月単位に絞ってからJSTで日付キー化）。
- 日付パースは厳密に（不正な `date`/`month` は404か空一覧に安全側で倒す。既存の月別アーカイブのバリデーションに倣う）。
- 既存の `lib/archive.ts` / `paginatedFindMany` のページング契約を流用する。

## 受け入れ基準（検証可能・原文）
- [ ] `/tags` で全タグが記事数付きで一覧表示され、各タグから該当記事一覧（`/tags/[tag]`）に遷移できる。
- [ ] グローバルナビ等から `/tags` に到達できる。タグ名で該当記事に辿り着ける。
- [ ] タグ一覧・記事数は公開記事のみを対象にしている（held/scheduled/rejected を含まない）。
- [ ] アーカイブがカレンダー（日付グリッド）表示になり、記事のある日が強調される。
- [ ] カレンダーの日をクリックすると、その日の公開記事一覧（`/archive/[date]` 等）が表示される。
- [ ] 前月/翌月の移動ができ、日付境界がJSTで正しい（JSTでその日に公開された記事がその日に出る）。
- [ ] 記事の無い日・未来日は空一覧としてエラーにならない。不正な日付は安全に扱う（404/空）。
- [ ] `npm test` が全てGreen（タグ集計・日別集計・JST日付キー化の純関数に最小限のテストを追加）。
