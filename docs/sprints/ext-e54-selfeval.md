# 拡張E54 自己評価レポート（修正版: 実データ検証で判明した不具合の修正）

## 実装した内容（今回の修正差分）
実データ（パッチ26.14）検証で判明した「スキル/ステータスのラベルが見出しに誤昇格する」不具合を修正。
`src/lib/generation/compose.ts` の `extractPatchSectionsInternal`（`extractPatchSectionsDeterministic`／
`extractPatchChangesDeterministic` が共用する内部パーサー）を以下のとおり修正した。

- **アドホック見出しヒューリスティックを廃止**: `isAdHocHeadingCandidate`（「⇒を持たず直後に変更行が
  続く短い行」を見出し候補とみなす関数）を削除。呼び出し箇所（チャンピオン上限超過後などで
  `currentChampion`/`currentOther` が共に null の状態）もあわせて削除し、該当する短い行はすべて
  「見出しにはせず、次の⇒変更行への文脈（`prevLine`）として前置されるだけ」に変更。
- **非チャンピオン節の見出しはキーワード行のみ**: `isSectionKeywordHeadingLine`（`SECTION_KEYWORD_HEADING_TERMS`
  ＝「アイテム」「ルーン」「アリーナ」「メイヘム」「システム」「バグ修正」「その他」を含む短い行）のみを
  見出しとして採用する一本化（`メイヘム` をキーワードに追加）。スキル記号(Q/W/E/R/固有スキル/パッシブ)や
  「〜のダメージ/反映率/移動距離/生成量」等の項目ラベルは見出しに昇格しない。
- **宙に浮いた変更は単一「その他の変更点」にまとめる**: チャンピオン節・キーワード節のどちらにも
  属さない `⇒` 変更（チャンピオン上限[12体]超過分・章見出し外の変更）は、個別に見出し化せず
  総称見出し `GENERIC_OTHER_HEADING`（「その他の変更点」）に集約する（従来から存在した総称見出し
  ロジックを維持しつつ、アドホック見出しに奪われていた分もすべてここに合流するよう修正）。
- **同一見出しのセクションをマージ/重複排除**: 新規ヘルパー `getOrCreateOtherSection` を追加し、
  非チャンピオンセクションの生成箇所すべて（キーワード見出し・総称見出しの双方）をこのヘルパー経由に
  統一。既存の同名見出し（例: 本文中に2回現れる「バグ修正」）があれば新規作成せず既存セクションに
  追記する（複数の同名セクションが生成されない）。

## 既知の問題・懸念点
- セクション見出し推定は引き続きbest-effort（明示的なキーワード行が無いまま章が切り替わる等の
  構造の乖離には対応しない設計・非目標のまま）。
- チャンピオン上限（12体）を超えた分の変更は、個別チャンピオン名は失われ「その他の変更点」に
  ラベル付きでまとまる仕様（チャンピオン最大数の有界化は既存仕様どおり維持）。
- 本番の実パッチノート（26.14含む今後の回）での見え方は次回の実データ取得時に再確認が望ましい。
