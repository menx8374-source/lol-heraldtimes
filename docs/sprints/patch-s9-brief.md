# パッチ刷新S9 — チャンピオン変更の見出しを「チャンピオンの強化/弱体化/調整」に変更

パッチ記事のチャンピオン3グループ見出しを、ユーザー要望により「主な〜」から「チャンピオンの〜」に変更する。**表示文言のみの小変更**。AI不使用。対象: Web。

## 背景
- 現状のチャンピオン3分類グループ見出しは「**主な強化 / 主な弱体化 / その他の調整**」（S3/S6で導入、S8でchampion限定）。
- ユーザー要望: 「**チャンピオンの強化 / チャンピオンの弱体化 / チャンピオンの調整**」に変更（「主な〜」をやめる）。アイテム章「アイテムの変更」はそのまま。

## 含まれる機能
### F-S9-1: 見出し文言の変更（公式パッチ記事）
- `src/lib/generation/compose.ts` の `composeDetailedPatchBody`（DOM経路）で、チャンピオン3グループ見出しを変更:
  - 「主な強化」→「**チャンピオンの強化**」
  - 「主な弱体化」→「**チャンピオンの弱体化**」
  - 「その他の調整」→「**チャンピオンの調整**」
- 冒頭サマリや目次(toc)の該当見出し参照も同じ文言に揃える（目次リンクのラベルが見出しと一致するように）。

### F-S9-2: 見出し文言の変更（PBE記事）
- `src/lib/generation/pbe-compose.ts` でも同じ3グループ見出しを使っている場合、同様に「チャンピオンの強化/弱体化/調整」に変更（公式記事とPBE記事で文言を統一）。

### F-S9-3: テスト更新
- これらの見出し文字列（「主な強化」等）をアサートしている既存テスト（generation-compose-patch-dom.test.ts・pbe-compose.test.ts 等）を新文言に更新する。他の検証内容は変えない。

## 制約・非目標
- **表示文言の変更のみ**。抽出ロジック・3分類判定(direction)・アイテム章・S4デザイン・出典・目次構造・その他の挙動は一切変えない。
- AI不使用・逐語維持（変更内容テキストは不変）。DBスキーマ変更なし・新規依存なし。fact/summaryモード・非パッチ記事・他ソースは不変。

1. パッチ記事(26.14等フィクスチャ)で、チャンピオングループ見出しが「チャンピオンの強化/弱体化/調整」になる。目次ラベルも一致。

4. 既存テストが新文言で全Green・他の検証は回帰しない。
