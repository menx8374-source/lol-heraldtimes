# 拡張スプリント E14: 新デザイン（ニュースメディア調）＋現行/新デザインのトグル切替

対象プラットフォーム: web（既存アーキテクチャに従う）

## 背景・ユーザー決定
参考サイトの比較検討の結果、**「ニュースメディア調（NYT/Vox系の報道メディア風）」の新デザイン**を採用する。
現行デザインと新デザインを、**ライト/ダークモードと同じ要領でトグル切替できる**ようにする（既定は現行、
新デザインは切替でオプトイン）。字体はユーザー指定の游ゴシック系スタックを用いる。

## 含まれる機能

### F-E14-1: デザイン切替の基盤（ライト/ダークと同方式）
既存のダークモード実装（`data`/クラス＋no-flashスクリプト＋localStorage＋Tailwind v4）を**そっくり真似て**、
デザイン軸を追加する。テーマ（light/dark）とデザイン（classic/news）は**独立した2軸**（4通り全て成立させる）。
- `<html>` に **`design-news` クラス**を付け外しする（現行=クラス無し=classic、新デザイン=`design-news`）。ダークの `dark` クラスと同じ流儀。
- **DesignToggle** クライアントコンポーネントを新設（`theme-toggle.tsx` を雛形に）。クリックで `<html>` の `design-news` クラスを付け外しし、`localStorage`（キー例 `lol-matome:design`、値 `classic`|`news`）に保存。初期値は `useState` 遅延初期化（`theme-toggle` と同方式。`suppressHydrationWarning` はボタンのラベルのみ）。
- `layout.tsx` の `<head>` に、テーマの `NO_FLASH_THEME_SCRIPT` と同様の **`NO_FLASH_DESIGN_SCRIPT`** を追加し、描画前に `localStorage` を読んで `design-news` クラスを同期的に付与（ちらつき防止）。埋め込むのは固定の静的スクリプトのみ（ユーザー入力・DBデータを混ぜない）。
- DesignToggle を **ThemeToggle の隣**（サイトヘッダー）に配置。ラベルは現行/ニュースが分かるもの（例: 「📰 ニュース」/「◇ 現行」）。
- 既定（初回訪問・未保存）は **classic（現行デザイン）**。

### F-E14-2: ニュースメディア調スキン（新デザイン）の適用
`design-news` クラスが付いたときの見た目を、報道メディア風にする。**classic（クラス無し）の見た目は一切変えない**。
実装は globals.css の**アンレイヤー（レイヤー外）CSS**を `.design-news`（およびダーク併用時 `.dark.design-news`）にスコープして行う
（globals.css のコメントどおり、アンレイヤーCSSは Tailwind の utilities レイヤーより優先されるため、既存のTailwindユーティリティを上書きできる）。
安定して狙えるセレクタが無い共有コンポーネント（サイトヘッダー・記事カード・見出し・カテゴリバッジ・まとめレス枠・コメント・サイドバーwidget・ボタン/リンク等）には、**最小限のセマンティックなクラス名/`data-*`フック**を付与して、それを `.design-news` 配下でスタイルする。

**字体（news時。ユーザー指定・厳守）**:
```
游ゴシック体, "游ゴシック Medium", "Yu Gothic Medium", YuGothic, "ヒラギノ角ゴシック Pro", "Hiragino Kaku Gothic Pro", メイリオ, Meiryo, Osaka, "ＭＳ Ｐゴシック", "MS PGothic", sans-serif
```
（body・見出し双方。見出しは太め weight でエディトリアルなコントラストを付ける。classic時は現行フォントのまま）

**ニュースメディア調のビジュアル指針（news時。ライト基準／ダークは対になる値で）**:
- 地色: 白（ライト）/ ほぼ黒（ダーク）。文字: ほぼ黒 / オフホワイト。
- アクセント: **クリムゾン**（ライト `#b3121f` 目安／ダークは明るめ `#ff5a67` 目安）。リンク・カテゴリ・強調・ランキング番号等に一貫使用。
- 記事カード: **角丸ボックス/影をやめ、ヘアライン罫線（下線）で区切る**（一覧が新聞の記事リスト風に）。サムネイルは角丸小。
- カテゴリ: 塗りチップではなく**小さめ太字クリムゾンのラベル**（字間わずかに広め）。
- 見出し（セクション見出し・記事タイトル）: 太字ゴシックでコントラスト強め。
- サイドバーwidget: 角丸カードをやめ、**太い上罫（黒）＋見出し**の新聞コラム風。
- まとめレス枠（`ReactionGroupView`）: 1枠内のレスを細い罫線で区切る現状を活かしつつ、news配色（白地・細罫・ゴシック）に。
- コメント（`CommentRow`）: まとめレスと区別できる差別化は維持しつつ、news配色（クリムゾン系アクセント）に馴染ませる。
- ボタン/リンク/リアクション・投票ボタン: news配色（クリムゾンアクセント）。角丸は控えめ。
- 情報密度は現行同様に保つ（回遊・広告接触を損なわない）。
- **ライト・ダーク双方**で視認性・コントラストを担保（design×themeの4通り全て崩れない）。

### スコープ（この1スプリントの対象）
主要な閲覧・回遊面を news 化する: サイトヘッダー/グローバルナビ、記事一覧カード（`ArticleCard`/`ArticleList`）、セクション見出し、カテゴリバッジ、記事ページ（タイトル・まとめレス枠・コメント・出典・広告枠ラベル）、サイドバー（人気ランキング/タグ/新着コメント等のwidget）、ボタン/リンク、フッター。固定ページ（法務・攻略等）は最低限「フォント・地色・リンク色」が news に追従すれば可（各要素の作り込みは必須ではない）。classic は完全据え置き。

## 実装原則（CLAUDE.md）
- 既存のダークモード実装（`theme-toggle.tsx`・`layout.tsx` の no-flashスクリプト・`globals.css` の `@custom-variant`/`.dark` 上書き・cascade layers の注意書き）を必ず読み、同じ流儀で実装する。
- テスト必須(TDD-lite): デザイン軸の状態決定・localStorageキー・初期値ロジックなど、明確な入出力を持つ純粋部分に最小限のテストを書く（例: 初期デザイン決定関数、no-flashスクリプトが正しいクラス名/キーを使うことの検証）。純粋な見た目（配色・罫線）自体はテスト不要。**テーマ（dark）関連の既存テストを壊さないこと**。
- 表示のみの変更。公開限定・モデレーション・リアクション等の**機能面の不変条件は一切変えない**。
- シークレットのハードコード禁止。**新規依存は追加しない**（フォントはシステムフォントスタックのみ。Webフォントの外部読込やライブラリ追加はしない）。
- アクセシビリティ: トグルに `aria-label`。フォーカス可視。`prefers-reduced-motion` を尊重（既存挙動を壊さない）。
- README に、デザイン切替の存在（ヘッダーのトグルで現行/ニュースを切替・localStorage保存）を最小限追記。
