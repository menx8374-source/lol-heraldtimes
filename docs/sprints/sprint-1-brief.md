# Sprint 1 brief — 記事データモデルと閲覧サイトの土台を立ち上げる

> 仕様書 `docs/spec/lol-matome-sokuhou-spec.md` から Sprint 1 該当部分を原文のまま抜粋。generator/evaluator の主参照先。

## 対象プラットフォーム
`web`（閲覧者向けの公開サイト＋自動運営のバックエンド／バッチ処理）。閲覧画面はスマートフォン・PC 双方のブラウザで崩れず読めるレスポンシブ表示を前提とする。

## 含まれる機能: F1

### F1. 閲覧サイトの土台（トップ記事一覧・個別記事ページ）
- 説明: 閲覧者が、トップページで新着まとめ記事の一覧（サムネイル・煽りタイトル・カテゴリ・投稿日時）を見て、クリックすると個別記事ページで本文・出典リンク・投稿日時を読める。参考サイトに倣ったまとめ速報型のレイアウト（記事カードが縦に多数並ぶ一覧＋個別記事）。
- 優先度: Must
- 受け入れ基準:
  - [ ] トップページに記事カードが新しい順（投稿日時降順）で最低10件並び、各カードにタイトル・カテゴリ名・投稿日時・サムネイル領域が表示される。
  - [ ] 記事カードのタイトルをクリックすると、その記事の個別ページに遷移する。
  - [ ] 個別記事ページに、タイトル・本文（見出し＋段落構造）・投稿日時・カテゴリ・出典リンク（1件以上）・「AI により自動生成された記事です」の注記が表示される。
  - [ ] スマートフォン幅（横 375px 相当）と PC 幅（横 1280px 相当）の両方で、レイアウトが崩れず（横スクロールが発生せず）記事が読める。
  - [ ] 存在しない記事 URL にアクセスすると 404 相当のページが表示され、トップへ戻る導線がある。

## このスプリントの受け入れ基準（終了時にデモできる状態）
- [ ] サンプル記事（最低10件・タイトル／本文／カテゴリ／出典リンク／投稿日時を持つ）が投入された状態で、トップページに記事カードが投稿日時降順で並ぶ。
- [ ] 記事カードをクリックすると個別記事ページに遷移し、タイトル・見出し／段落構造の本文・投稿日時・カテゴリ・出典リンク・「AI により自動生成された記事です」注記が表示される。
- [ ] 横 375px と横 1280px の両方で横スクロールが発生せず記事が読める。
- [ ] 存在しない記事 URL で 404 相当ページが表示され、トップへ戻る導線がある。
- [ ] 記事本文中の見出し・段落・出典リンクが正しく構造化されて表示される（1本の長文ベタ書きになっていない）。
