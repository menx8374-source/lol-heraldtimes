# Sprint 8 brief — 広告枠差し込みと SEO・構造化データ・サイトマップで収益化・流入基盤を整える

> 仕様書 `docs/spec/lol-matome-sokuhou-spec.md` から Sprint 8 該当部分を原文のまま抜粋。generator/evaluator の主参照先。

## 対象プラットフォーム
`web`。スマートフォン・PC 双方のブラウザで崩れず読めるレスポンシブ表示を前提とする。

## ⚠ このスプリントの実装方針（AdSense タグはプレースホルダー）
**AdSense アカウント開設・審査申請は Non-Goal**。システムは広告タグを差し込める枠と、差し込む広告コードを**設定で受け取る仕組み**まで担う。広告コード未設定時はプレースホルダー枠を表示する。AdSense ポリシー違反配置（コンテンツ誤認・クリック誘導）はしない。

## 含まれる機能: F12, F13

### F12. 広告枠差し込み・収益化配置
- 説明: 参考サイトのマネタイズを踏襲し、記事内（見出し前後）・記事一覧・サイドバー・記事末尾等に広告枠を差し込める。広告コード（AdSense 等のタグ）は設定で受け取り、各枠に反映する。AdSense ポリシーに反する配置（コンテンツ誤認・クリック誘導）はしない。
- 優先度: Must
- 受け入れ基準:
  - [ ] 個別記事ページに、記事上部・本文中（見出し間）・記事末尾・サイドバーの各広告枠が存在し、枠の位置が視認できる（広告コード未設定時はプレースホルダー枠が表示される）。
  - [ ] トップ記事一覧内にも一定間隔で広告枠が差し込まれる。
  - [ ] 広告コードを設定に入れると、その内容が各広告枠に出力される（枠に任意の広告タグ文字列を反映できることを確認できる）。
  - [ ] 広告枠がコンテンツ本文やナビゲーションと誤認される配置になっておらず、記事本文と視覚的に区別できる（枠にラベルまたは区切りがある）。
  - [ ] 広告枠を含んでもスマホ・PC でレイアウトが崩れず、記事本文が読める。

### F13. SEO・構造化データ・サイトマップ・OGP
- 説明: 検索流入とディスプレイ広告収益のため、各ページに適切なタイトルタグ・メタディスクリプション・OGP（SNS シェア時のカード）・構造化データ（記事情報）を出力し、サイトマップと robots を提供する。
- 優先度: Should
- 受け入れ基準:
  - [ ] 各個別記事ページに、記事タイトルを反映した `<title>`、内容を要約したメタディスクリプション、OGP（og:title／og:description／og:image／og:url）が出力される。
  - [ ] 各個別記事ページに記事の構造化データ（見出し・公開日時・カテゴリ等を含む記事メタ情報）が出力される。
  - [ ] 全公開記事とカテゴリページを列挙したサイトマップが生成され、アクセスできる。
  - [ ] robots 指定が提供され、収集・公開してはならない領域（管理／保留キュー等）がクロール対象から除外される。
  - [ ] トップ・カテゴリ・記事の各ページで `<title>` が固有（ページごとに異なる）である。
