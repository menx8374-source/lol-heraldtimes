# パッチ刷新S4 — LoL公式風デザイン（黒/紺背景・金/teal・スキル/アイテムカード）

`docs/patch-accuracy-research.md` §5・§7 S4。ユーザーの主要要望「パッチ・公式関連ページをLoL公式風（背景を黒や紺、LoLアイコンの金色味、リンクボタンもLoLらしく）」を実装。
S1〜S3で正確な対象/スキルキー/変更前後/意図/アイコンが揃った本文を、**LoL公式パッチノートの世界観**で見せる。**AI不使用（純CSS/表示）**。対象: Web。

## 背景（S1〜S3の到達点）
- 誤帰属ゼロの構造抽出（S1）→ patchChangeブロックで本文反映（S2）→ 正しいアイコン表示（S3）まで完成。**現状は素朴な見た目**。
- S4で「パッチ記事本文だけをLoL公式のダーク意匠」にする。**サイト全体（一覧・ヘッダ・他記事）はライト基調のまま不変**。
- 色は憶測でなく**公式CSS実測**を軸に: 金 `#C8AA6E`・区切り `#3b4353`（Riot公式パッチノートページのCSSから確認済み）。

## カラートークン（research §5.1・パッチ本文スコープ限定）
パッチ本文ラッパ `[data-lol-patch]` の中だけで使う固定色（サイトの `dark:` ユーティリティに依存しない専用トークン。ライト/ダーク両モードで同じLoL意匠にする）:
```
--lol-gold-bright:#F0E6D2  --lol-gold:#C8AA6E(★実測)  --lol-gold-2:#C89B3C  --lol-gold-3:#785A28  --lol-gold-deep:#463714
--lol-blue:#0AC8B9(teal)   --lol-blue-2:#0397AB       --lol-blue-3:#005A82
--lol-bg:#010A13(最深)     --lol-bg-2:#091428(パネル紺) --lol-panel:#1E2328  --lol-divider:#3b4353(★実測)
--lol-text:#CDBE91(本文・AA確保のため明るめ)  --lol-buff:#0AC8B9(強化teal)  --lol-nerf:#E84057(弱体赤)  --lol-adjust:#C8AA6E(調整金)
```

## 含まれる機能

### F-S4-1: パッチ本文ラッパとトークン適用
- パッチ記事（`sourceType==="riot"` の detailed、= patchChangeブロックを含む本文）を `data-lol-patch` のラッパで囲み、その内側だけ上記トークンを適用（`globals.css` に `[data-lol-patch]{ ... }` のスコープCSS、またはTailwind任意値）。
- ラッパの地は紺 `#091428`〜黒 `#010A13` のグラデ or 単色。角丸・内側パディング。**パッチ本文以外（サイトのヘッダ/フッタ/一覧/他カテゴリ記事）には一切影響しない**こと。

### F-S4-2: チャンピオン/アイテム変更カード（PatchChangeBlockView 意匠）
1対象=1カード:
- 上辺に金の細ライン（`border-top:2px solid #C89B3C`）、面 `#091428`、角丸、金の薄枠 `#463714`。
- ヘッダ: **対象アイコン**（S3の画像）を**金の丸/角丸枠**（`border:2px solid #C8AA6E`）で囲み、右に対象名を**金文字 `#F0E6D2`**・太字。direction バッジ（強化=teal地/弱体化=赤地/調整=金地の小ラベル）。
- **変更意図（intent）**: `#C8AA6E`寄りの控えめ色・小さめ斜体でサブ表示。
- スキル行: **スキルアイコン**（小・角丸枠）＋ `R - 連発ミサイル` を金文字。直下に各変更 `stat：before ⇒ after`。**before はグレー（`#7A7A7A`）＋やや弱め、after は direction 色（buff=teal/nerf=赤/adjust=金）で強調**。`⇒` は金の矢印。逐語のテキストは不変。

### F-S4-3: セクション見出し・目次・公式リンクボタン
- **3グループ見出し**「主な強化」=teal下線、「主な弱体化」=赤下線、「その他の調整」=金下線（`border-bottom` ＋ 見出し文字は金 `#F0E6D2`）。
- **冒頭サマリ**: 紺地カードに金文字で強化N/弱体M/調整K体。
- **目次(toc)**: 紺地 `#091428`＋金見出し＋teal `#0AC8B9` リンク（ホバーで明teal）。
- **公式リンクボタン**（ユーザー添付の青ボタンをLoL化）: 現行 `linkButton`（article-body-view）をパッチ記事内では **紺地・金枠・金文字＋ホバーで金地反転**に（`bg-[#091428] border border-[#C8AA6E] text-[#C8AA6E] hover:bg-[#C8AA6E] hover:text-[#091428]`）。ラベル頭に `▶`。例「▶ パッチ26.14 公式パッチノートを読む」。

### F-S4-4: サイト全体との両立・アクセシビリティ
- ダーク意匠は `[data-lol-patch]` 内にスコープし、**既存の `dark:` ユーティリティ（サイトのダークモード）と衝突しない固定色**で当てる（パッチ記事はライト/ダーク両モードで同じLoL見た目）。
- **コントラストAA**: 金文字 `#F0E6D2`/`#C8AA6E` on 紺 `#091428` はAA可。本文は `#CDBE91`〜`#F0E6D2` 寄りで小文字でも読めるように。teal/赤の変更値も紺地でAAを満たす明度に。
- レスポンシブ: カード・アイコン・before⇒after がモバイルで縦積み崩れしない（既存のレスポンシブに沿う）。画像は `max-width:100%`。
- ヒーロー画像（パッチバナー）は既存のまま。パッチ本文ブロックのみダーク化。

## 制約・非目標
- **AIは使わない**（純CSS/表示）。抽出・分類・テキストは不変（S1〜S3の成果を見せるだけ）。**逐語維持**。
- **サイト全体のテーマ・他記事・一覧・ヘッダ/フッタは変更しない**（パッチ本文スコープ限定）。`docs/dashboard.html` は触らない（protect-immutable）。
- DBスキーマ変更なし・新規npm依存なし。カラーは research §5.1 の実測金/区切りを軸に、他Hextech色は近似で可（パッチ本文限定のため実害小）。
- 未適用/速報経路（S5）は本スプリントでは扱わない。

## テスト（必須・実ネット非依存）
1. patchChangeブロック・3グループ見出し・目次・公式リンクボタンが `data-lol-patch` スコープ内でLoLトークン（金/紺/teal・direction色分け）でレンダリングされる（renderToStaticMarkup でクラス/スタイル/data属性を検証）。
2. before=グレー弱め・after=direction色（buff=teal/nerf=赤/adjust=金）で色分けされる。⇒矢印・スキルアイコン枠・対象アイコン金枠が付く。
3. パッチ本文以外（他カテゴリ記事・一覧・ヘッダ）に `data-lol-patch` スタイルが漏れない（スコープ確認）。既存の article-body-view/記事ページ/一覧テストが回帰しない。
4. 公式リンクボタンが紺地金枠＋▶ラベルになる。目次リンクが機能する（S3までのアンカーが壊れない）。

## 受け入れ基準
1. `npx vitest run` 全Green・`npx tsc --noEmit`・`npm run build`・`npm run lint` 通過。
2. パッチ記事本文が**黒/紺地＋金/tealのLoL公式風**で表示され、対象/スキルアイコンが金枠、変更前後が color 分け、公式リンクボタンがLoL意匠になる。一覧・他記事・ヘッダは従来ライトのまま不変。
3. コントラストAA・レスポンシブ崩れなし。AI不使用・逐語維持・DBスキーマ変更なし・新規依存なし。

## 評価基準（evaluator向け・Playwright推奨）
- テスト全Green・build/tsc/lint通過・コンソールエラー0。
- **Playwrightでパッチ記事を実表示し、黒/紺地＋金/teal意匠・対象/スキルアイコンの金枠・before⇒after色分け・公式リンクボタン(紺地金枠)を目視/スクショ確認**。一覧・他記事がライトのまま崩れないことも確認。プレビュー画像を保存。
- スコープ漏れが無い（他記事がダーク化しない）。コントラストが読める。
- 受け入れ基準1〜3を満たす。
