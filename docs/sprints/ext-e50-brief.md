# 拡張E50 — 海外の反応の原文英語併記を廃止＋記事冒頭にサムネ画像（ヒーロー）を表示

運用フィードバック起点。対象: Web（表示）。

## 背景（なぜ）
1. 海外の反応(Reddit)記事は日本語訳＋原文英語を併記（拡張E47/E49）していたが、**原文は不要**。日本語訳のみにする。
2. 記事ページの**冒頭にサムネ画像を貼りたい**（＝一覧だけでなく記事の先頭にもキービジュアルを出す）。

## 含まれる機能

### F-E50-1: Reddit反応記事の原文英語併記を廃止（日本語訳のみ）
- `src/lib/generation/compose.ts` の `buildReactionDisplayLines`（拡張E49）で、訳がある場合に付けていた
  `original`（英語原文）を**設定しない**（`text`＝日本語訳のみ）。行数一致・不一致どちらのケースでも `original` を付けない。
  - 翻訳が全く無い場合（reddit翻訳失敗・5ch）は従来どおり抽出行そのまま（`text` のみ・`original` 無し）。＝挙動不変。
- 結果、reddit記事は**日本語訳だけ**が並ぶ（「原文: …（英語）」が出なくなる）。5chは元から `original` 無しで不変。
- 表示側 `ResLines`（article-body-view.tsx）の原文表示コードは、`original` が来なければ何も描画しないため**そのままでよい**
  （最小変更＝生成側で付けないだけ）。任意で原文描画コードの削除も可（やる場合はテストも更新）。
- 逐語方針: reddit は元々「海外の反応として意図された日本語訳」で、原文は併記用だった。原文を出さないだけで訳の生成は不変。

### F-E50-2: 記事冒頭にサムネ画像（ヒーロー）を表示
- `src/app/articles/[slug]/page.tsx` で、本文（`ArticleBodyView`）の**直前**に記事のサムネ画像をヒーローとして表示する。
  - 使う描画: 既存 `ArticleThumbnail`（`thumbnailUrl` + `category` + `slug`）を再利用（反応記事のチャンピオンアート
    フォールバック＝拡張E38 も効く）。大きめ・横幅いっぱい・角丸で表示（`className` で hero サイズ指定。例
    `w-full max-h-96 object-cover rounded-lg`）。alt は記事タイトル。
  - **重複回避（必須）**: 本文の**先頭ブロックが image**（＝パッチ記事の公式バナー、拡張E42）の場合はヒーローを**出さない**
    （二重画像防止）。判定は `article.body[0]?.type === "image"`。
  - それ以外（反応記事＝5ch/reddit、及び image で始まらない記事）はヒーローを表示。反応記事は
    サムネ（チャンピオンアート/Redditプレビュー画像）が冒頭に出る。
- 一覧カード・OGP・sitemap 等の既存挙動は不変。

## 制約・非目標
- 生成ロジック（hotness・翻訳の有無・SEO・moderation）には触れない（原文を付けない点と表示の追加のみ）。新規依存なし。
- reddit の翻訳自体は維持（日本語訳は出す。原文併記だけ廃止）。5ch・riot の本文は不変。
- ヒーロー画像は既存 `ArticleThumbnail` の安全URL判定・フォールバックをそのまま使う（新たな画像取得はしない）。

## テスト（必須・実API/実ネット非依存＝スタブLLM／レンダリング）
1. `buildReactionDisplayLines`/`buildReactionBlocks`（reddit・スタブ翻訳成功）: 各行が `text`＝日本語訳のみで `original` を持たない
   （原文併記が付かない）。翻訳失敗時は従来どおり `text`＝英語・`original` 無し。5ch は不変（`original` 無し）。
2. 記事ページ（レンダリング）: 本文先頭が image ブロックでない記事は、本文の前にヒーロー画像（`<img>` サムネ）が描画される。
   本文先頭が image の記事（パッチ）はヒーローを**描画しない**（二重画像なし）。
3. 反応記事（thumbnailUrl 有り/チャンピオンアートフォールバック）でヒーローに妥当な src が入る。
4. 既存の compose/article-body-view/seo-output/記事ページ系テストが回帰しない（原文併記前提のテストは「原文なし」に更新）。

## 受け入れ基準
1. `npx vitest run` 全Green（新規/更新含む）。
2. `npx tsc --noEmit`・`npm run build`・`npm run lint` 通過。
3. Reddit記事が日本語訳のみ（原文英語なし）。記事ページ冒頭にサムネ画像が出る（パッチ記事は既存バナーのみで二重にならない）。
   逐語（訳の生成）不変・新規依存なし。

## 評価基準（evaluator向け）
- テスト全Green・build/tsc/lint通過。mock/生成/表示が回帰しない（コンソールエラー0）。
- reddit記事に原文が出ないこと、記事冒頭のヒーロー画像（image先頭記事では非表示）がテストで確認できる。
- 受け入れ基準1〜3を満たす。
