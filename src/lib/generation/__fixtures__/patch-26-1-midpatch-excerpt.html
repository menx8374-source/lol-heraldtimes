ミッドパッチアップデート

2026年1月9日（太平洋標準時） ミッドパッチアップデート

週末を迎える前に、パッチ26.1にいくつかの変更点を加えることにしました。内容は早期バランス調整、ランダムミッド：メイヘムへの軽微な修正、そして実装準備の整ったバグ修正です。新シーズン開始早々、数々のご報告やフィードバックをお送りいただきありがとうございました！

アフェリオス

アフェリオスのスキルにはクリティカル判定を持つものが多く、その分のパワー増加を抑える調整を行いましたが、依然としてゲーム内で突出した強さのチャンピオンとなっていました。アフェリオスの攻撃力＆攻撃速度ビルドは弱めなのでそのパワーは維持しつつ、彼の瞬間火力を若干低下させました。

固有スキル - 殺す者と導く者

  • Eのスキルレベルごとの増加脅威：5.5 ⇒ 4.5

グレイブス

この新シーズン、グレイブスは明らかに弱体化しており、事前措置として取り入れていたクリティカルダメージ軽減策の一部は不要のように見受けられました。そこで今回、クリティカル攻撃の威力が増すよう手を貸しました。グレイブスのクリティカルヒットはかなり複雑なのですが、要するに、全弾丸が命中した場合、クリティカルヒットは非クリティカルヒットの2倍のダメージを与えるようになりました。

固有スキル - ニュー・デスティニー

  • クリティカルスケーリング：追加クリティカルダメージの35% ⇒ 追加クリティカルダメージの50%
  • クリティカル最大ダメージ：非クリティカルの1.8倍 ⇒ 非クリティカルの2倍

ケイル

トップレーンでは獲得XPが増加するため、Qを最大まで上げたケイルは本パッチではかなり強い状態になっていました。そこで、攻撃力を増加させる魔力系アイテムが少なかった時期に追加した魔力スケーリングを一部削除します。

固有スキル - 聖なる上昇

  • スタックごとの攻撃速度：6%（魔力100ごとに+1%） ⇒ 6%

Q - 裁きの射光

  • マナコスト：70 / 75 / 80 / 85 / 90 ⇒ 60 / 70 / 80 / 90 / 100
  • スロウ効果：26 / 32 / 38 / 44 / 50% ⇒ 25 / 30 / 35 / 40 / 45%

エッセンス リーバー

  • トータルコスト：2900ゴールド ⇒ 3050ゴールド
  • レシピ：シーン + コールフィールド ウォーハンマー + アジリティ クローク + 350ゴールド ⇒ シーン + コールフィールド ウォーハンマー + アジリティ クローク + 500ゴールド
  • 攻撃力：55 ⇒ 50

ランダムミッドとランダムミッド：メイヘムのアップデート

  • ランダムミッドとランダムミッド：メイヘムから、アイテム「バスティオンブレイカー」を除外しました。
  • ガングプランクに対してオーグメント「処刑人」が現れないように一時的に無効化しました。これは想定外の相互作用を引き起こしていたためです。
  • オーグメント「閃光」を一時的に無効化し、関連する不具合を修正しています。
  • 同一オーグメントを複数回獲得してスタックすることを可能にしていた不具合を修正しました。
  • 「ストームレイザー」が2つショップに並ぶ問題を特定しました。
  • ゼリの攻撃速度が上限値を超えてしまう不具合を修正しました。（これはパッチ16.1実装時に修正されていましたが、パッチノートに記載されていませんでした）

バグ修正

  • 「アクチュアライザー」がマナコストを無限に増加させ得る複数の不具合を修正しました。
